1. **Se continuar com scripts separados, vai ter 104 dias de trabalho em paralelo e risco de inconsistência.**  
A fundação evita isso, mas se o prazo é curto e o foco é apenas conformidade, pode ser um desperdício de tempo.

2. **Geração distribuída é um negócio separado — não é o produto principal.**  
Se vender conformidade com art. 266, não precisa construir uma plataforma de energia solar.

3. **BDGD com 3.285 unidades PJ sem geração é uma base sólida para prefeituras.**  
Mas se o cliente é a prefeitura, isso muda o modelo: de “conformidade” para “ferramenta de visita”.

4. **Perda de participação do Piauí é um sinal de mercado fraco, não de oportunidade.**  
Não é argumento de venda — é um alerta para riscos no negócio.

5. **O risco maior é confundir conformidade com serviço de energia.**  
Se o produto é apenas o cadastro, não pode se expandir para gerar receita recorrente sem alinhamento com o cliente.
